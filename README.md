# template-2 — Туристический лендинг на Astro 5 + TypeScript

🔗 **Онлайн демо (Live Demo):** [https://template-2-lac.vercel.app/](https://template-2-lac.vercel.app/)

Современный статический лендинг турагентства с нулевой JS-перегрузкой (Zero-JS по умолчанию).

---

## 🚀 Особенности и архитектура

- **Фреймворк:** [Astro 5](https://astro.build/) (`output: "static"`), чистый HTML на выходе.
- **Типизация:** TypeScript в строгом режиме (`astro/tsconfigs/strict`).
- **Стилизация:**
  - `src/styles/global.css` — CSS переменные, сброс стилей, типографика, общие анимации.
  - Пост-обработка через `PostCSS`, `Autoprefixer` и `cssnano` (минификация в production).
- **Оптимизация изображений (astro:assets):**
  - Автоматическая конвертация изображений в WebP/AVIF.
  - Оптимизированный первый экран (LCP): `loading="eager"`, `fetchpriority="high"`, с предзагрузкой.
- **Производительность 100/100:**
  - Zero-JS гидратация (никаких тяжелых библиотек jQuery или Slick).
  - Нативный CSS scroll-snap слайдер отзывов с поддержкой тач-свайпов и стрелок.
  - Устранены Render-blocking ресурсы; шрифты подключены с `font-display: swap` и preconnect.
  - Микроразметка Schema.org (`TravelAgency` / `LocalBusiness`) и Open Graph / Twitter Cards.
- **Юридическое соответствие (152-ФЗ и GDPR):**
  - `/privacy` — полноценная страница Политики конфиденциальности.
  - `/consent` — страница Согласия на обработку персональных данных (ст. 9 152-ФЗ).
  - Интерактивный Cookie-баннер с гранулярным выбором категорий (технические, аналитические, маркетинговые) и кнопкой быстрого вызова настроек из футера.
- **Отправка заявок по SMTP на nice-dev@list.ru:**
  - Серверный маршрут `/api/lead` с отправкой детальных HTML-уведомлений о лидах.
  - Гибкая конфигурация SMTP в `.env` (хост, порт, логин, пароль приложения).
- **Многоуровневая защита от спама (Anti-Spam):**
  - **Honeypot:** скрытое поле-ловушка для перехвата автоматических ботов.
  - **Time-based analysis:** отсечение мгновенных отправок роботов (< 2 секунд).
  - **Rate Limiting:** защита от флуда и спам-атак (до 5 заявок за 10 мин с одного IP).
  - **Санитизация:** очистка входящих данных от потенциальных XSS/HTML-инъекций.

## 🛠️ Локальная разработка

1. Установка зависимостей:

   ```bash
   npm install
   ```

2. Запуск локального сервера разработки:

   ```bash
   npm run dev
   ```

   Сервер запустится по адресу: `http://localhost:4321`

3. Сборка статического сайта:

   ```bash
   npm run build
   ```

   Скомпилированные статические файлы будут сохранены в директорию `dist/`.

4. Локальный предпросмотр сборки:

   ```bash
   npm run preview
   ```

5. Проверка типов и линтинг:
   ```bash
   npm run check
   ```
